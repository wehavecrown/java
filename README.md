# Java Core Mastery Repository

##  Overview
This repository provides a comprehensive, in-depth exploration of Java programming, from fundamental concepts to advanced features. Each topic is presented with detailed explanations and practical code examples.

##  Topics Covered

### Core Java Fundamentals
- Java Virtual Machine (JVM) architecture
- Basic syntax and data types
- Control flow and arrays
- Object-Oriented Programming (OOP) principles

### Object-Oriented Programming
- Inheritance and polymorphism
- Interfaces and abstract classes
- Encapsulation and access modifiers
- Method overriding and overloading

### Exception Handling
- Try-catch-finally blocks
- Custom exceptions
- Best practices

### Functional Programming
- Lambda expressions
- Functional interfaces
- Method references

### Multithreading
- Thread creation and management
- Synchronization
- Executor framework
- Concurrent collections

### Collections Framework
- List, Set, Map, Queue implementations
- Sorting and searching
- Custom comparators

### Stream API
- Intermediate and terminal operations
- Parallel streams
- Advanced stream operations

### JVM Internals
- Memory management
- Garbage collection
- Performance optimization

##  Getting Started

### Prerequisites
- Java JDK 11 or higher
- IDE (IntelliJ IDEA, Eclipse, or VS Code)
- Maven (optional)

### Running the Examples
```bash
# Clone the repository
git clone https://github.com/yourusername/java.git

# Navigate to project directory
cd java

# Compile and run individual files
javac src/main/java/com/java/basics/HelloWorld.java
java src/main/java/com/java/basics/HelloWorld
